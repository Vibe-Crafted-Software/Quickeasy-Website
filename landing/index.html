House rules

How these pages are built.

  • Same shape every time. Hero → the problem → what changes → how it works → what is included → the honest objections → one CTA. Problem cards and solution cards match one-for-one on purpose.
  • No stock photography. These pages carry no images. They are read, not looked at.
  • No invented proof. No client logos, testimonials or statistics unless we have permission and a source. "Since 1998" and "more than twenty years in South African print" are the claims we can actually stand behind.
  • Every claim traces to the product. If it is not a real BOS module or a published price, it does not go on the page.
  • Pricing is always one click away. Every page links to /pricing/, because the first objection is always cost.
  • Pillars link down, capability pages link up. That mesh is doing real SEO work — do not strip the "Related" sections when editing copy.
  • Thai. Only /th/manufacturing-erp/ and /th/printing-signage-packaging/ exist so far, and both are a machine-drafted first pass awaiting native-speaker review.

Not on this list

Deliberate gaps.

  • Competitor comparison pages. We position against a category ("bolt-on stock apps", "spreadsheets"), never against a named rival.
  • "Best ERP" listicles. Those results belong to review aggregators. Not worth the effort.
  • Next up, once Search Console has enough data to confirm them: quoting software, stock control software, warehouse management, ERP for engineering, food & beverage ERP, furniture manufacturing software.

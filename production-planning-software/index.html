Production Planning Software

Plan, schedule and track every job from one board — with the costing, stock and customer data already attached.

A production plan is only as good as the data behind it. In BOS the schedule is built from real job cards, real machine capacity and real material availability, because planning, stock and costing are the same system.

What a connected plan changes

Scheduling stops being a guess.

Three things become possible the moment the plan shares data with the rest of the business.

Promise dates you can keep

Capacity and material availability are visible when you quote, not discovered when the job hits the floor.

See work in progress as it happens

Shop-floor tracking updates the schedule live, so a delay on one machine reflows the plan instead of surfacing at month-end.

Know the cost while it is still running

Hours and materials post against the job as they are consumed, so an overrun is something you catch, not something you audit.

Production Planning

Plan, schedule and track every job

Multiple interactive views — Kanban boards, jobs view, materials view, timekeeping, board view and Gantt charts — for flexible production management.

  • Dashboard for Work Centres — monitor Work Centre loading to optimise resource utilisation and avoid bottlenecks.
  • Support for Theory of Constraints (TOC) — plan around production constraints to maximise efficiency.
  • View estimated vs actual time & quantity — track planned vs real-time performance to improve scheduling accuracy.
  • Job filtering by key dates — filter jobs by due, required, or active dates for precise scheduling.
  • Support for multiple routings — manage alternative workflows for different jobs or products.
  • Track material requisition progress — monitor material availability throughout the production process.
  • Task progress (quantity & hours) — keep track of hours worked and quantities produced for each task.
  • Routing status with colour codes — identify task status instantly using colour-coded indicators.
  • Operator tracking — track which operators are assigned to specific jobs to ensure accountability.
  • Gantt diagram — visualise production timelines and task dependencies in a Gantt view.
  • Reset planning from now — adjust plans dynamically to start from the current moment.
  • Adjust tasks for dependencies — reschedule tasks based on changing dependencies and priorities.
  • Batch orders by start date & status — organise orders efficiently by grouping tasks with similar start dates or statuses.
  • Job scheduling by required date — plan jobs around the customer's promised date to meet deadlines.
  • Board view — visualise tasks across cost centres and workstations.
  • Time to Start (TTS) indicator — know when each task is scheduled to begin to avoid delays.
  • Custom task descriptions — add specific information to tasks for better clarity.
  • Late & busy indicators — identify overloaded workstations or delayed tasks at a glance.
  • Auto-set start status — automatically mark tasks as "ready" based on predefined models.
  • Group tasks by cost centre — assign and manage tasks based on workstations or departments.
  • Add notes to tasks — provide additional instructions or updates directly within each task.

Non-conformance Reporting

  • ISO compliant — ensure quality standards with ISO-compliant reporting tools.
  • Link NCR to Work Orders — track and resolve non-conformances through corrective Work Orders.
  • Root cause analysis & corrective actions — record problems, containment, corrective actions and evaluation for continuous improvement.
  • Track material & labour costs — monitor the impact of non-conformances on resources and costs.

Reporting

  • Real-time cost tracking — access up-to-the-minute data on production costs for informed decisions.
  • Interactive reporting — drill down, filter, and sort data to analyse production performance.
  • Customisable output — export reports in formats that suit business needs.
